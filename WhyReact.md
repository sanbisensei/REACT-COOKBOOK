## Why React

- React is a component based library of Javascript for building interfaces.
- React uses Declarative Approach , instead of manually manipulating the DOM using methods like 'document.getElementById()' we describe how the ai should look like and React will take care of it.
- React has a virtual DOM. it efficiently updates UI using Virtual DOM. If we make any changes React compares the previous Virtual DOM with the new one and updates only the necessary part of the real DOM instead of reloading the entire page. Result : fast UI updates & Better performance.
- it has Component based Architecture for reusability , easier maintenance, scalability.

- React is fantastic for state management , it manages dynamic data using state . when state changes -> UI updates automatically.
